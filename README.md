<h1 align="center">HVSorter</h1>
<p align="center">CLI для сортировки изображений по ориентации</p>

---

CLI-утилита для сортировки изображений на горизонтальные и вертикальные. Определение ориентации через sharp, прогресс-бар и цветной вывод.

- **Сортировка** — разделение фото по ориентации (H/V).
- **sharp** — быстрое определение размеров без полной загрузки.
- **CLI UX** — прогресс-бар, цветной вывод, figlet-баннер.

## Быстрый старт

```bash
git clone https://github.com/AlexanderKuzikov/HVSorter.git
cd HVSorter
npm install
node index.js
```
